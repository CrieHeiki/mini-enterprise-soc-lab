# Screenshots checklist

Publish only reviewed, sanitized images. Suggested filenames:

- `dashboard-overview.png` — alerts, unique findings, detection distribution, timeline, investigation queue.
- `endpoint-alert-100410.png` — CASE-001, original `data.agent_name` and finding ID.
- `ad-alert-100411.png` — CASE-002, correlated AD identity/group fields.
- `services-active.png` — `soclab-endpoint`, `soclab-ad`, `soclab-adapter` active.

**Redact** desktop usernames, IPs that are not meant to be public, tokens, internal URLs, any unrelated notifications, secrets and personally identifying information. Never expose real passwords or private key material. Store image files here after review; this template includes no screenshots.
